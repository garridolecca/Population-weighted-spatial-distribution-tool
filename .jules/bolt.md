## 2024-03-20 - [ArcGIS FeatureLayer Query Optimization]
**Learning:** Querying web services with `arcgis.features.FeatureLayer` defaults to returning all fields, which for large datasets like the US Census Redistricting Blocks creates massive network payloads, latency, and memory consumption. Intermediate layers created using `.save()` on `FeatureSet` objects write to disk, contributing to slow I/O.
**Action:** Always use the `out_fields` parameter when calling `.query()` to limit data retrieval to only the necessary attributes. Additionally, utilize `memory` workspace for intermediate ArcPy feature classes and `arcpy.env.scratchGDB` for temporary FeatureSet `.save()` locations to minimize disk operations. Move all temporary data cleanup (`DeleteField`, `Delete`) to a `finally` block with `arcpy.Exists()` checks to ensure proper execution even upon early exit or failure.
