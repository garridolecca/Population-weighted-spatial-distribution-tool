## $(date +%Y-%m-%d) - Optimize ArcGIS FeatureLayer web query
**Learning:** When querying a remote ArcGIS `FeatureLayer` using `web_layer.query()`, by default, the query returns all fields in the dataset. When the tool performs an intersection against a census layer, only the geometric boundaries and the field determining the population weight (i.e. `population_field`) are actually required. Returning dozens of unused census demographic fields across many block features can severely impact the download speed over the network.
**Action:** When querying `FeatureLayer` features via the web, explicitly specify `out_fields` to restrict the returned payload to only what is necessary (e.g. `out_fields=population_field`). Geometry is implicitly included unless `return_geometry=False` is set.
